A broadsheet front page — **THE WORLD TODAY, Thursday 19 November 2026** — that
sums up the day's world news in a single 1024×1024 image. Twelve photo cards
cover the biggest stories, and an "Also on" column carries the rest of the
day, so all 28 stories fit on one page. The lead story is the worldwide
rollout of GTA VI: gamers enter Vice City at dawn. The masthead reads
**THE WORLD TODAY**, dated Thursday 19 November 2026; the twelve cards sit
in a 3×4 grid, each with a red number badge, section tag, headline and
two-line deck, and the "Also on" column lists stories 13–28 one line each.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/path/to/out python3 main.py
```

This decodes `entry.png.b64` (pure Python standard library, no network) and
writes `entry.png` (1024×1024, under 1 MiB) into the output directory.
